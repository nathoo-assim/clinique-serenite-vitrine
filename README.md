# HMS Clinique Sérénité — vitrine

Page de présentation du produit **HMS Clinique Sérénité**, un système de gestion
hospitalière (HMS) conçu pour un établissement de santé **avec hospitalisation**.

**Voir la page en ligne** → https://nathoo-assim.github.io/clinique-serenite-vitrine/

## Ce que montre la page
- Le **parcours patient** de bout en bout : accueil, salle d'attente, consultation,
  laboratoire / imagerie, hospitalisation, pharmacie, caisse, portail.
- Les **modules métier** et la vue direction.
- La **facturation tiers-payant** — le HMS calcule, la comptabilité facture.
- Les principes **Sérénité** : donnée déclarée vs validée, jamais bloquant,
  aucun diagnostic automatique, accessibilité.
- Des **captures d'écran réelles** de l'application.

## Détails techniques
- Page unique et **autonome** : [`index.html`](index.html) — aucune dépendance
  externe (styles, scripts et images embarqués).
- Thème clair et sombre, responsive.
- Publiée via **GitHub Pages** (branche `main`, dossier racine).

> Les écrans utilisent des **données de démonstration** — aucune donnée réelle de patient.
